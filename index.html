Архів документів

Document Archive — a private macOS app

«Архів документів» — нативний застосунок для macOS, який веде реєстр службових документів (листи, акти, накладні) і зберігає файли в спільній папці Google Drive користувача, щоб два MacBook працювали з одним архівом.

Застосунок не має власного сервера: реєстр зберігається на Mac користувача, а файли — лише в його власному Google Drive. Застосунок призначений для внутрішнього використання й не поширюється публічно.

Document Archive is a native macOS app that keeps a registry of documents and stores the files in the user's own shared Google Drive folder so that two Macs can work with the same archive. It has no backend server and is intended for private internal use only.
